# ADR-0006: MIT license

- **Date:** 2026-11-10 · **Status:** Accepted
- **Decision:** MIT. The hackathon rules require a visible open-source license
  (15_HACKATHON_PITCH_AND_SUBMISSION). Nothing in the project sources requires copyleft
  or a patent grant.
- **Alternative:** Apache-2.0 (explicit patent grant). Switching is easy before the
  first public push if the owner prefers it.
